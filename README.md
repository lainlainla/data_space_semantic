# Data Space Semantic

TIDE C 组用这个仓库研究数据空间的语义互操作，记录代码分析、模型映射和验证结果。第一阶段围绕 P1 研究数据资源，核对如何用选定的 DCAT/DCAT-AP 基线表达目录信息，以及 TIDE 需要补充哪些定义。

- [Issues](https://github.com/exclbprime/data_space_semantic/issues)记录任务、负责人、预期产物和当前进度。
- [Pull Requests](https://github.com/exclbprime/data_space_semantic/pulls)集中审查代码、分析文档和验证证据。
- [贡献指南](CONTRIBUTING.md)说明如何下载、提交修改和评估进度。

项目材料见 [TIDE 项目任务书](teams_files/TIDE_Project_Requirements/TIDE_Research_Task_Plan.md)和 [C 组语义互操作任务清单](teams_files/TIDE_Project_Requirements/TIDE_C_Group_Semantic_Task_List.md)。清单可用于认领任务和核对交付证据。

A 组的接口和交付约定见[跨组待议](跨组待议.md)。
